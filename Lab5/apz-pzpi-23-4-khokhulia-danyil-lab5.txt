За бажання, можна оформити демо у вигляді elevator pitch-а системи як вашого продукту який ви пропонуєте клієнтам.
ОПИС ВИКОНАНОЇ РОБОТИ
     3.1 Короткий опис проєкту
      WashConnect — це комплексна екосистема автоматизованого управління мережею пралень. Система складається з чотирьох інтегрованих компонентів: веб-застосунку для адміністраторів та користувачів (React), кросплатформного мобільного клієнта для зручного користування зі смартфона, IoT-модулів (ESP32) для кожної пральної машини та єдиної хмарної серверної частини (ASP.NET Core). Платформа реалізує повний цикл послуг: реєстрацію, пошук вільних машин, бронювання на визначений час, управління активною сесією прання, безконтактну оплату через внутрішній цифровий гаманець, а також збір телеметрії (рівень вібрації, статус блокування дверцят) з фізичних пристроїв у реальному часі.
3.2 Заплановані функції 
Серверна частина - Для бекенду планувалося створення REST API з JWT-авторизацією для безпечної ідентифікації користувачів та IoT-пристроїв. Основні функції мали охоплювати управління бронюваннями, сесіями прання та обробку транзакцій віртуального гаманця. Було передбачено реалізацію адаптивного рівня доступу до даних із використанням Microsoft SQL Server для локальної розробки та PostgreSQL для хмарного середовища. Також інфраструктурний план включав контейнеризацію системи за допомогою Docker та налаштування автоматизованого розгортання на платформі Render.
Веб-клієнт - У рамках веб-клієнта передбачалася кросплатформна робота безпосередньо в браузері за принципом SPA-архітектури. Інтерфейс мав містити зручний каталог пралень з відображенням статусів машин онлайн. Окремо планувалася розробка адміністративної панелі для модерації користувачів та управління резервними копіями шляхом експорту й імпорту даних у форматі JSON. Для зручності користувачів була запланована повноцінна інтернаціоналізація застосунку українською та англійською мовами.
Мобільний клієнт - Мобільний клієнт проєктувався як зручний нативний застосунок для смартфонів. Його головним завданням був швидкий пошук та бронювання пральних машин, точний розрахунок вартості прання, а також інтерактивне управління сесією із можливістю запуску та екстреного скасування процесу. Додатково планувався функціонал поповнення віртуального гаманця та зручного перегляду балансу.
Апаратний IoT-модуль - Для апаратного модуля ставилося завдання встановлення безпечного HTTPS-з'єднання з хмарним сервером. Фізичний пристрій мав забезпечувати надійну та періодичну передачу телеметрії, зокрема інформації про статус машини, поточний рівень вібрації та стан блокування дверцят.
     3.3 Реалізовані функції
Серверна частина та Cloud-інфраструктура: На даному етапі побудовано надійний REST API на платформі ASP.NET Core. Впроваджено гнучку логіку вибору провайдера бази даних через Entity Framework Core, використовуючи UseSqlServer для локального середовища розробки та UseNpgsql для хмарної бази PostgreSQL. Також успішно реалізовано стратегію розгортання через Docker. Для оптимізації розміру та безпеки створеного образу використано багатоетапну збірку (Multi-stage build), а локальна оркестрація сервісів повністю автоматизована за допомогою файлу docker-compose.yml. Крім того, налаштовано безперервний CI/CD пайплайн на платформі Render, де при кожному коміті в гілку main відбувається збірка Docker-образу та автоматичне застосування міграцій бази даних.
Веб-клієнт: Клієнтський застосунок реалізовано як надзвичайно швидкий SPA на базі React 18, мови TypeScript та збирача Vite. Мережевий шар стабільно обробляється через бібліотеку Axios з використанням interceptors для автоматичного додавання JWT-токенів до заголовків запитів. Управління станом успішно побудовано на поєднанні інструменту TanStack Query для кешування серверного стану та бібліотеки Zustand для управління локальним станом користувача. Також повністю впроваджено багатомовність за допомогою i18next та створено ізольовані захищені маршрути (ProtectedRoute) для доступу адміністраторів до модуля Data Management.
Мобільний клієнт: Розроблено повноцінний нативний Android-додаток мовою Kotlin з використанням сучасного декларативного UI-фреймворку Jetpack Compose (Material 3). Його архітектура жорстко базується на патерні MVVM та принципах Clean Architecture із поділом на Presentation, Domain та Data шари. Для ефективної ін'єкції залежностей застосовано фреймворк Dagger Hilt. Мережева взаємодія реалізована через бібліотеки Retrofit та Gson, а локальне збереження JWT-токенів надійно забезпечується через Jetpack DataStore Preferences із використанням кастомного AuthInterceptor. Уся ключова бізнес-логіка, що стосується авторизації, розрахунку ціни та старту прання, чітко інкапсульована у відповідні Use Cases, такі як LoginUseCase, PreviewPriceUseCase та StartSessionUseCase.
IoT-інтеграція (ESP32): Для мікроконтролера ESP32 розроблено прошивку мовою C++. За допомогою стандартних бібліотек WiFi.h, HTTPClient.h та ArduinoJson.h пристрій успішно проходить SSL-рукостискання з віддаленим сервером. Безпосередньо в коді реалізовано функцію sendTelemetry(), яка формує JSON-пакет зі статусом машини та рівнем вібрації. Цей пакет періодично відправляється через захищений HTTPS POST-запит на бекенд, завдяки чому фізичний пристрій повністю синхронізовано з хмарною системою.


3.4 Заплановані, але не виконані функції
     Серед запланованого, але тимчасово залишеного поза поточним скоупом розробки функціоналу, варто виділити WebSocket підключення в реальному часі. На даний момент обмін даними між сервером, мобільним клієнтом та IoT-пристроєм працює через періодичні REST-запити (використовуються техніки long polling та refetchInterval у React Query), а створення повноцінного двостороннього каналу відкладено на наступні ітерації. Що стосується фінансових транзакцій, зараз у системі реалізовано внутрішній цифровий гаманець, проте безпосередня інтеграція з реальними платіжними провайдерами, такими як Stripe або LiqPay, наразі імітується. Крім того, вхід у систему через сторонні сервіси за протоколом OAuth 2.0 (через облікові записи Google або Apple) наразі не впроваджено; авторизація працює виключно через класичний механізм з використанням електронної пошти та пароля.















ВИСНОВКИ
     У ході виконання роботи було успішно спроєктовано та реалізовано комплексну екосистему WashConnect, яка об'єднує масштабований хмарний бекенд, IoT-модулі на мікроконтролерах, а також кросплатформні веб- та мобільний клієнти в єдиний злагоджений продукт. За два семестри розробки створено повноцінну відмовостійку систему з надійною Docker-інфраструктурою, що цілком готова до вирішення реальних бізнес-завдань з автоматизації мережі пралень.
